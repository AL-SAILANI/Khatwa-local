# External practice and level-check sources (named by the third-party course)

Only the sites are listed. Several links arrived shortened, so the exact sub-pages are unknown; use the site roots.
Nothing here is copied into the product; they are candidates for a "practice more" links page and for content ideas.
Licensing of any material from these sites has not been checked.
